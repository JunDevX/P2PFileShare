# P2P File Share Engine

[![NET](https://img.shields.io/badge/.NET-8.0-512BD4?logo=dotnet)](https://dotnet.microsoft.com/)
[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20macOS%20%7C%20Linux%20%7C%20Android-lightgrey)](https://dotnet.microsoft.com/)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

Консольное клиент-серверное приложение для прямой передачи файлов между устройствами в локальной вычислительной сети (LAN, Radmin VPN, Tailscale) с графическим оформлением интерфейса командной строки.

Передача данных осуществляется по протоколу Peer-to-Peer (P2P) с использованием транспортного протокола TCP без привлекаемых сторонних облачных серверов.

[Официальная документация](https://JunDevX.github.io/P2PFileShare/docs/)

---

## Функциональные возможности

* **Автоматическое обнаружение (Auto-Discovery):** Поиск активных узлов и файлов в подсети через широковещательные запросы UDP Broadcast (порт 8888) без необходимости ручного ввода IP-адресов.
* **Терминальный интерфейс:** Графическое оформление командной строки на базе библиотеки `Spectre.Console`, включающее диалоговые меню и индикаторы прогресса.
* **Потоковая передача данных:** Передача файлов блоками фиксированного размера (64 КБ) через `NetworkStream`, что предотвращает избыточную нагрузку на оперативную память при работе с крупными файлами.
* **Контроль целостности:** Расчет и валидация контрольных сумм по алгоритму SHA-256 до и после завершения передачи.
* **Кроссплатформенность:** Поддержка операционных систем Windows, macOS, Linux, а также Android (в среде Termux).

## Архитектура решения

```text
P2PFileShare/
├── Models/
│   └── FileMetadata.cs      # Объект передачи данных (DTO): имя файла, размер, хеш SHA-256, TCP-порт
├── Network/
│   ├── DiscoveryService.cs  # Модуль UDP-вещания и сканирования локальной сети
│   ├── Sender.cs            # Серверная часть: подготовка файла и обработка TCP-подключений
│   └── Receiver.cs          # Клиентская часть: получение потока данных и сохранение на диск
├── UI/
│   └── MacTerminal.cs       # Модуль форматирования и отрисовки элементов интерфейса
└── Program.cs               # Точка входа в приложение и маршрутизация режимов работы
