P2P File Share Engine

Файлы. Напрямую.
Без лишних серверов.

Документация консольного P2P-клиента для обмена файлами между устройствами в одной локальной сети. Просто запустите приложение и начните передачу.

Peer-to-peer ⌁ UDP Broadcast ⌘ Windows · macOS · Linux · Android
↗
Прямая передачаФайлы передаются между устройствами без стороннего облака.
◎
Автопоиск устройствUDP Broadcast помогает находить устройства без ручного ввода IP.
⌘
Несколько платформИнструкции для популярных настольных ОС и Android через Termux.

Ключевая особенность: устройства обнаруживают друг друга в локальной сети, а передача выполняется напрямую. Для работы не требуется сторонний облачный сервер.

Начало работы

01 Быстрый запуск

Если вы скачали готовый исполняемый файл со страницы релизов GitHub:

  1. Откройте раздел Releases репозитория.
  2. Загрузите бинарный файл, соответствующий вашей операционной системе.
  3. Запустите файл и следуйте инструкциям на экране.
Платформа 01

02 Windows x64

Запуск готового релиза

Скачайте P2PFileShare-win-x64.exe и запустите его двойным кликом. При первом запуске брандмауэр Windows может запросить разрешение на работу в сети — выберите «Разрешить доступ для частных сетей».

Самосборка из исходников

# Клонирование и переход в папку
git clone https://github.com/JunDevX/P2PFileShare.git
cd P2PFileShare

# Компиляция в единый .exe
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true

# Результат:
# bin/Release/net8.0/win-x64/publish/P2PFileShare.exe
Платформа 02

03 macOS Apple Silicon · Intel

Запуск готового релиза

Загрузите P2PFileShare-osx-arm64 для M1/M2/M3/M4 или P2PFileShare-osx-x64 для Intel Mac. Откройте Terminal в папке с файлом и выполните:

chmod +x P2PFileShare-osx-arm64
./P2PFileShare-osx-arm64

Обратите внимание: если macOS блокирует запуск бинарного файла, откройте Системные настройки → Конфиденциальность и безопасность и проверьте доступные варианты разрешения запуска.

Самосборка из исходников

# Для Apple Silicon (M1–M4)
dotnet publish -c Release -r osx-arm64 --self-contained true /p:PublishSingleFile=true

# Для Intel Mac
dotnet publish -c Release -r osx-x64 --self-contained true /p:PublishSingleFile=true
Платформа 03

04 Android Termux

Запуск готового релиза

  1. Установите приложение Termux.
  2. Предоставьте доступ к файлам: 
    termux-setup-storage
  3. Перенесите файл P2PFileShare-linux-arm64 в память телефона и запустите в Termux: 
    cd ~/storage/downloads
chmod +x P2PFileShare-linux-arm64
./P2PFileShare-linux-arm64

Самосборка из исходников на ПК

dotnet publish -c Release -r linux-arm64 --self-contained true /p:PublishSingleFile=true

Подключение

06 Настройка сети

Для корректного взаимодействия устройств проверьте следующие условия:

  • Оба устройства подключены к одной локальной Wi-Fi сети или объединены через виртуальную сеть (например, Radmin VPN, Tailscale или ZeroTier).
  • В настройках брандмауэра разрешён UDP-порт 8888 для автопоиска и TCP-порт 9999 для передачи данных.

Совет: если устройства не видят друг друга, проверьте настройки сети и правила брандмауэра на обоих устройствах.
