P2P File Share Engine Documentation

Добро пожаловать в официальную документацию консольного P2P-клиента обмена файлами в локальной сети с интерфейсом в стиле macOS Terminal.

Ключевая особенность: Передача файлов происходит напрямую между устройствами без сторонних облачных серверов. Использование UDP Broadcast избавляет от необходимости вводить IP-адреса вручную.

Быстрый запуск из GitHub Releases

Если вы скачали готовый исполняемый файл со страницы релизов GitHub:

  1. Перейдите в раздел Releases репозитория.
  2. Загрузите бинарный файл, соответствующий вашей операционной системе.
  3. Запустите файл и следуйте инструкциям на экране.

Windows (x64)

Запуск из готовых релизов:

Скачайте P2PFileShare-win-x64.exe и запустите его двойным кликом. При первом запуске брандмауэр Windows может запросить разрешение на работу в сети — выберите «Разрешить доступ для частных сетей».

Самосборка из исходников:

# Клонирование и переход в папку
git clone https://github.com/JunDevX/P2PFileShare.git
cd P2PFileShare

# Компиляция в единый .exe
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true

# Файл будет сформирован по пути:
# bin/Release/net8.0/win-x64/publish/P2PFileShare.exe

macOS (Apple Silicon & Intel)

Запуск из готовых релизов:

  1. Загрузите файл P2PFileShare-osx-arm64 (для M1/M2/M3/M4) или P2PFileShare-osx-x64 (для Intel).
  2. Откройте Terminal.app в папке с файлом и разрешите запуск: 
    chmod +x P2PFileShare-osx-arm64
./P2PFileShare-osx-arm64
Обратите внимание: Если macOS блокирует запуск бинарника, откройте Системные настройки → Конфиденциальность и безопасность и нажмите кнопку «Все равно открыть».

Самосборка из исходников:

# Сборка для Apple Silicon (M1-M4)
dotnet publish -c Release -r osx-arm64 --self-contained true /p:PublishSingleFile=true

# Сборка для Intel Mac
dotnet publish -c Release -r osx-x64 --self-contained true /p:PublishSingleFile=true

Android (через Termux)

Запуск из готовых релизов:

  1. Установите приложение Termux (из F-Droid).
  2. Предоставте доступ к файлам: 
    termux-setup-storage
  3. Перенесите скачанный бинарный файл P2PFileShare-linux-arm64 в память телефона и запустите в Termux: 
    cd ~/storage/downloads
chmod +x P2PFileShare-linux-arm64
./P2PFileShare-linux-arm64

Самосборка из исходников на ПК:

dotnet publish -c Release -r linux-arm64 --self-contained true /p:PublishSingleFile=true

Linux (x64)

Запуск из готовых релизов:

chmod +x P2PFileShare-linux-x64
./P2PFileShare-linux-x64

Самосборка из исходников:

dotnet publish -c Release -r linux-x64 --self-contained true /p:PublishSingleFile=true

Настройка сети

Для корректного взаимодействия устройств убедитесь, что соблюдены следующие условия:

  • Оба устройства подключены к одной локальной Wi-Fi сети или объединены через виртуальную сеть (Radmin VPN, Tailscale, ZeroTier).
  • В файрволе открыты порты: 8888 (UDP) для автопоиска и 9999 (TCP) для передачи данных.
